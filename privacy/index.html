Privacy summary

Projects, settings and installed packages are stored locally, with automatic Android backup disabled in this release. Package downloads contact PyPI, and code you run may connect to external services. Support communication is voluntary.

01المطور والتواصل

هذه سياسة خصوصية PyPocket، تطبيق تطوير Python لأندرويد من تطوير Ahmed Alenzi في المملكة العربية السعودية. للتواصل بشأن الخصوصية: pypocket.support@gmail.com.

01Developer & contact

This is the privacy policy for PyPocket, a Python development application for Android, developed by Ahmed Alenzi in Saudi Arabia. Privacy contact: pypocket.support@gmail.com.

02المشاريع والملفات المحلية

تُحفظ المشاريع والإعدادات والمكتبات المثبتة في مساحة التطبيق الخاصة على الجهاز. لا يتضمن PyPocket حسابات أو مزامنة سحابية أو خدمات تحليلات أو إعلانات أو إرسالًا تلقائيًا لملفات المشاريع أو تقارير الأعطال. عطّلنا النسخ الاحتياطي السحابي ونقل بيانات التطبيق التلقائي عبر إعدادات Android في هذه النسخة. قد تختلف أدوات النقل الخاصة بمصنّعي الأجهزة. يمكنك تصدير مشروع يدويًا إلى الجهة التي تختارها في منتقي مستندات Android، بما فيها مزوّد سحابي تختاره أنت.

02Local projects & files

Projects, settings and installed packages are stored in private app storage on the device. PyPocket includes no account, cloud sync, analytics, advertising, automatic project upload or crash-reporting service. This release disables Android cloud backup and automatic app-data transfer through Android configuration. Manufacturer migration tools may vary. You can manually export a project to the destination you choose in Android's document picker, including a cloud provider you select.

03الإنترنت وتثبيت المكتبات

يرسل البحث عن حزمة أو تنزيلها اسم الحزمة والإصدار المطلوب وتفاصيل طلب الاتصال إلى PyPI ومضيف ملفاتها باستخدام HTTPS. تتلقى هذه الجهات عنوان IP ومعلومات العميل وقد تحتفظ بسجلات الخادم وفق سياساتها؛ لا نتحكم في مدة احتفاظها. قد تشمل إحصاءات تنزيل PyPI الرابط المطلوب والبلد التقريبي وفق إشعار خصوصيتها؛ ولا يعني هذا وجود أداة تحليلات داخل PyPocket. لا تُرفق شيفرة المشروع بهذه الطلبات. تظهر مخرجات Console محليًا في الذاكرة ولا تُرسل تلقائيًا للدعم، لكن شيفرة المستخدم قد تحفظها أو ترسلها. تفتح روابط الدعم والخصوصية في متصفح خارجي، ولا تُرسل رسالة بريد إلا إذا اخترت ذلك من تطبيق البريد.

03Network & package installation

Package lookup and downloads send the requested package name, version and connection details to PyPI and its file hosts over HTTPS. These providers receive IP address and client metadata, and may retain server logs under their own policies; we do not control their retention. PyPI download statistics may include requested URLs and approximate origin country under its privacy notice; this is not an analytics SDK inside PyPocket. Project source is not attached to these requests. Console output is displayed locally in memory and is not automatically sent to support, though user code can save or transmit it. Support and privacy links open in an external browser, and email is sent only if you choose to send it using your mail app.

04الشيفرة والمكتبات الخارجية

تعمل شيفرة Python والمكتبات في عمليات منفصلة تشترك في هوية وصلاحيات التطبيق على Android. هذه ليست بيئة عزل مستقلة لكل مشروع؛ يمكن للشيفرة التي تشغّلها الوصول إلى جميع ملفات PyPocket المسموح للتطبيق الوصول إليها، وتعديلها، واستخدام الإنترنت. يمكن للمكتبات الخارجية إرسال بيانات بحسب وظائفها. لا تعني مطابقة SHA-256 أن المكتبة موثوقة أو خالية من الشيفرة الضارة. ثبّت وشغّل فقط الشيفرات التي تثق بها.

04User code & third-party packages

Python code and packages run in separate processes sharing PyPocket's Android identity and permissions. This is not an isolated sandbox for each project: code you run can access and modify all PyPocket files available to the app and use the internet. Third-party packages may transmit data according to their behavior. A matching SHA-256 checksum does not prove that a package is trustworthy or free from malicious code. Install and run code you trust.

05مراسلات الدعم

إذا راسلت بريد الدعم، نستقبل عنوان بريدك ومحتوى الرسالة وأي مرفقات تختار إرسالها، ونستخدمها للرد والمساعدة. يُعد طلب الدعم مغلقًا بعد انتهاء معالجته وإرسال الرد النهائي. نحتفظ بمراسلات طلب الدعم لمدة 90 يومًا بعد إغلاقه، ثم نحذفها من سجلات الدعم التي نتحكم بها، إلا إذا استلزم القانون أو التزام نظامي الاحتفاظ بها مدة أطول. لا يُقصد بهذه المدة رسائل لم يُغلق طلبها بعد.

05Support communications

If you email support, we receive your email address, message, and any attachments you choose to send, and use them to respond and troubleshoot. A support request is considered closed once handling is completed and a final response is sent. We retain support correspondence for 90 days after the request is closed, then delete it from support records under our control, unless a longer retention period is legally required. This 90-day period does not apply to requests that are still open.

06الأذونات

قد يستخدم التطبيق اتصال الإنترنت لتحميل المكتبات أو تشغيل طلبات شبكة يطلبها المستخدم، ووصول الملفات التي يختار المستخدم فتحها أو استيرادها أو تصديرها. تتحدد الأذونات الدقيقة بحسب نسخة التطبيق ونظام Android.

06Permissions

The app may use internet access for package downloads and user-initiated networking, and file access for content you choose to open, import, or export. Exact permissions depend on the Android version and app release.

07الاحتفاظ بالبيانات والحذف

حذف مشروع يزيل ملفاته المحلية. إزالة مكتبة تلغي وجودها في البيئة النشطة؛ قد تبقى ملفات في ذاكرة التنزيل المؤقتة أو البيئة السابقة إلى أن تُحذف تلقائيًا. مسح بيانات التطبيق أو إزالة PyPocket يحذف البيانات المحلية التي يملكها التطبيق، ولا يحذف نسخ المشاريع المصدّرة أو بيانات الجهات الخارجية. لحذف مراسلات الدعم قبل انتهاء مدة الـ90 يومًا، أرسل طلبًا إلى pypocket.support@gmail.com بعنوان «طلب حذف بيانات الدعم»، واذكر الرسالة أو الطلب المعني. سنراجع الطلب، وقد نتحقق من ملكيتك للمراسلات عند الحاجة، ثم نحذف البيانات الخاضعة لسيطرتنا أو نوضح أي التزام قانوني يمنع الحذف الفوري. يجب تنفيذ إجراء عملي لمراجعة الطلبات وحذف المراسلات بعد انقضاء مدة الاحتفاظ.

07Retention & deletion

Deleting a project removes its local files. Uninstalling a package removes it from the active environment, though copies may remain in download caches or earlier environments until cleanup. Clearing app storage or uninstalling PyPocket deletes app-owned local data but does not remove exported projects or third-party records. To request deletion of support correspondence before the 90-day period ends, email pypocket.support@gmail.com with the subject “Support Data Deletion Request” and identify the relevant message or request. We will review the request, verify your connection to the correspondence if needed, then delete data under our control or explain any legal obligation that prevents immediate deletion. A practical process for reviewing requests and removing correspondence after the retention period must be in place.

08Security

We aim to minimize unnecessary data access and use secure communications when supported, but cannot guarantee the safety of third-party code or packages. Avoid storing passwords or secret keys in shared projects.
